# Smart-Industrial-Safety-Monitoring-LPC2129
ARM7 LPC2129 based industrial safety monitoring system using LM35, PIR, and flame sensors with LCD, UART, and LED alerts.
# Smart Industrial Safety Monitoring System

## Overview
An embedded industrial safety monitoring system developed using the ARM7 LPC2129 microcontroller. It monitors temperature, worker movement, and flame conditions to identify potential safety hazards.

## Hardware Components
- LPC2129 (ARM7)
- LM35 Temperature Sensor
- PIR Motion Sensor
- Flame Sensor
- 16x2 LCD
- UART0 Serial Communication
- Green, Yellow, and Red LEDs

## Features
- Real-time temperature monitoring
- Worker movement detection
- Flame detection
- SAFE, WARNING, and DANGER status classification
- LCD-based status display
- UART terminal monitoring
- LED-based safety indication

## Technologies
- Embedded C
- ARM7
- LPC2129
- ADC
- GPIO
- UART
- LCD Interface

## Applications
Industrial safety monitoring, fire detection, and workplace hazard monitoring.
